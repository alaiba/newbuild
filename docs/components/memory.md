## Review dependencies

Do not select an exact kit until the motherboard review resolves:

- final motherboard model
- QVL coverage
- ECC decision
- realistic 2×64 GB data rate
- relevant BIOS/AGESA maturity

## Required output

The memory review must finish with:

1. exact kit/model recommendation
2. IC/vendor information where useful
3. QVL/support evidence
4. JEDEC and EXPO/XMP characteristics
5. expected stable operating settings
6. ECC/non-ECC rationale
7. stability-test procedure
8. Romanian availability and price
