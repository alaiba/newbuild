# CPU Deep Dive

Status: **Open**

## Scope

No CPU vendor, platform, socket or model has been selected.

The previously discussed **AMD Ryzen 9 9950X** is a reference candidate only.

## Review focus

Evaluate current viable CPU options for:

- development/build performance
- VM/container throughput
- single-thread responsiveness
- core/thread count versus real workload scaling
- virtualization capabilities
- memory capacity/support
- ECC implications
- power limits and efficiency
- sustained all-core thermals
- platform/chipset capabilities
- firmware/platform maturity
- expected 7–10 year usefulness
- future upgrade path where meaningful
- Romanian pricing and total platform cost

The comparison should include relevant AMD and Intel alternatives rather than asking only whether the 9950X is good enough.

Gaming performance matters only to the extent required for occasional Genshin Impact with the existing RTX 3060; it should not dominate CPU selection.

## Required output

Finish with:

1. workload-derived CPU requirements
2. serious candidate shortlist across viable platforms
3. benchmark evidence relevant to builds/productivity/VM-like workloads
4. efficiency and sustained-power comparison
5. memory/platform implications
6. exact CPU recommendation
7. rationale for rejecting the closest alternatives
8. expected cooling requirements
9. Romanian price/value and total platform-cost implications
