# New PC Build

A quiet, high-performance workstation built primarily for large Java/Android projects, local development services and occasional virtualization. **Stability and practical performance took priority over benchmark chasing.**

**Status (November 2026):** Assembled and in daily use with **Windows 11 Pro**. Initial CPU cooling, DDR5 memory and NVMe validation completed successfully; further GPU and peripheral checks remain open.

## Build at a glance

| Component | Configuration |
|---|---|
| CPU | AMD Ryzen 9 9950X3D |
| Motherboard | ASUS TUF GAMING B650E-E WIFI |
| RAM | 48 GB (2 × 24 GB) Crucial DDR5-5600 |
| SSD | Crucial T710 2 TB, PCIe 5.0 ×4 |
| GPU | NVIDIA RTX 3060 12 GB (reused) |
| Cooling | Thermalright Phantom Spirit 120 |
| Case | be quiet! Pure Base 501 Airflow |
| PSU | be quiet! Pure Power 13 M 850 W |
| OS | Windows 11 Pro |

**Initial results:** MemTest86 **4 passes, 0 errors**; NVMe sequential read/write **14.0 / 12.9 GB/s**; CPU peak **80.5 °C** at ~200 W in a short stress test. Normal workloads are smooth and the build is exceptionally quiet.

**Total new-hardware cost:** **10,093.93 lei**, purchased September 2026. The GPU was reused.
